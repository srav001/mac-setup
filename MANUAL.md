# Manual steps

1. **Rex**: install Rex Beta from the private beta link in Discord and launch it once. Enable **Remote Control** in **Rex > Settings > Server**; this lets connected Rex clients select the file's new session automatically. Re-run `./setup.sh`, then approve each **Change** dialog for text-file defaults. Command-click a text file in a terminal and double-click one in Finder to confirm both open visibly in Neovim.
2. **Sign-ins**: `claude`, `codex` and `opencode`. Their tokens never go in this repo.
3. **Privacy permissions**: grant Accessibility to AeroSpace when macOS asks. Apple does not let scripts grant these.
